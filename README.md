# 🧺 PowerDryClean – Rate List

A responsive and user-friendly **laundry and dry cleaning rate list website** developed for **PowerDryClean**. The project provides customers with a simple and organized way to explore available services and pricing across different categories.

## ✨ Features

- 📱 Fully Responsive Design
- 💰 Service Rate List
- 👕 Dry Cleaning Services
- 🧺 Wash & Fold Services
- 👔 Ironing Services
- 🧭 Easy Navigation
- 📱 Mobile-Friendly Interface
- 🎨 Clean and Modern UI
- ⚡ Fast and Lightweight Frontend

## 🛠️ Tech Stack

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactive functionality
