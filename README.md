# PowerDryClean Rate List

A responsive and user-friendly rate list website developed for *PowerDryClean* to display laundry and dry cleaning service pricing in a clean and organized format. The project was designed to provide customers with quick access to service information and pricing while maintaining a professional user experience.

## Features

- Responsive Design
- Service Rate List
- Dry Cleaning Services
- Wash & Fold Services
- Ironing Services
- Easy Navigation
- Mobile-Friendly Interface
- Clean and Modern UI

## Tech Stack

- HTML5
- CSS3
- JavaScript

## Installation

bash
git clone https://github.com/your-username/powerdryclean-rate-list.git
cd powerdryclean-rate-list


Open index.html in your preferred web browser.
